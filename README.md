# BilimIzde

Қазақ тіліндегі білім порталы. Мұнда Қазақстан университеттері, мамандық шифрлары, ҰБТ шектік балдары, 2025/2026 жылдардағы грант саны және шетелдік университеттер жинақталған. Сайт қазақ, орыс және ағылшын тілдерінде жұмыс істейді.

## Мүмкіндіктер

- **Грант есептегіш** — ҰБТ балы бойынша шектен өтетін мамандықтар, өткен жылғы өту балына жететіндері және 2026 жылғы грант саны.
- **113 мамандық** — шекті балл, бейіндік пәндер, 2023–2026 гранттары, Max/Min өту балдары (жалпы конкурс және ауылдық квота), оны оқытатын ЖОО-лар. Бетте іздеу және сала бойынша сүзгі.
- **81 ЖОО** — мамандықтар кестесі және әр мамандыққа грант конкурсына шекті балл (ЖОО кестесі немесе министрлік шегі), жатақхана, әскери кафедра, QS рейтингі, ресми логотип; студенттер пікірі мен талқылауы. Іздеу, қала және түр бойынша сүзгі.
- **Өткен жылдар** — 2025/2026 гранттарының салыстыруы, өту балдары, ЖОО бойынша ең төменгі балл (ҒЖБМ-нің 2026–2027 грант иегерлері тізімінен).
- **Магистратура** — 2026–2027 магистратура гранттары (132 топ), КТ емтиханы және мерзімдер.
- **ЖОО жаңалықтары** — БАҚ-тың RSS арналарынан сағат сайын жиналады (тек тақырып пен сілтеме).
- **44 шетелдік университет** — оқу ақысы, талаптар, тарихы.
- Университеттер картасы, ЖОО/мамандық салыстыру, мамандық таңдау тесті (25 сұрақ), ҰБТ жаттығуы, құжат чек-парағы мен күнтізбе, гранттар мен шәкіртақылар, 13 сұрақтық FAQ.
- **Менің жоспарым** — Google арқылы кірсең, серверде сақталады; **Таңдаулылар** — құрылғыда сақталады.
- **AI кеңесші** — сайттың базасынан жауап береді; `ANTHROPIC_API_KEY` берілсе, тіл моделі қосылады.
- Үш тіл (ҚАЗ / RU / ENG), қараңғы және ашық тақырып, телефонға бейімделген, PWA.

## Қалай жұмыс істейді

1. **Деректер** `backend/app/data/*.json` файлдарында сақталады. Әрқайсысы ресми дереккөзден: ЕПВО тізілімі (ЖОО мамандықтары), ҒЖБМ бұйрықтары мен грант иегерлерінің тізімі (гранттар, өту балдары), ЖОО ресми сайттары (шекті балл, жатақхана), ҰТО (ҰБТ, КТ), stat.gov.kz (жалақы), QS (рейтинг). Сайтта әр дерек жанында дереккөз сілтемесі тұр.
2. **Сервер** (FastAPI) бір сұраныспен (`/api/bootstrap`) барлық деректі береді, жаңалықтарды жинайды, пікірлер мен жоспарларды дерекқорда сақтайды (PostgreSQL немесе SQLite) және Firebase арқылы кіруді тексереді.
3. **Сайт** (HTML/CSS/JS, фреймворксыз) деректерді браузерде өңдейді: іздеу, сүзгі, есептегіш, тест бәрі серверге қайта жүгінбей жұмыс істейді, сондықтан жылдам.
4. **Орналастыру**: GitHub-қа `push` жасалса, Render сайтты өзі жаңартады.

## Компьютерде іске қосу

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload
```

- Сайт: https://bilimizde.onrender.com
- API құжаттамасы: http://127.0.0.1:8000/docs

AI-ды тіл моделімен іске қосу үшін (міндетті емес):

```bash
set ANTHROPIC_API_KEY=sk-ant-...        # Windows (cmd)
# export ANTHROPIC_API_KEY=sk-ant-...   # macOS / Linux
```

## Қосымша мүмкіндіктер (айнымалы арқылы қосылады)

Барлығы міндетті емес: айнымалы болмаса, сайт сол функциясыз қалыпты жұмыс істейді.
Render → сервис → **Environment** бөлімінде қосылады.

| Айнымалы | Не үшін |
|---|---|
| `BZ_SITE_URL` | Сайттың толық адресі (мысалы `https://bilimizde.onrender.com`). sitemap.xml, SEO беттері, Telegram-бот сілтемелері үшін |
| `BZ_ADMIN_KEY` | `/admin.html` статистика бетінің құпия кілті (өзің ойлап тап) |
| `DATABASE_URL` | Render PostgreSQL адресі. Болмаса — SQLite (тегін Render-де қайта іске қосқанда тазаланады) |
| `FIREBASE_PROJECT_ID`, `FIREBASE_WEB_CONFIG` | Google және телефон арқылы кіру. WEB_CONFIG — Firebase Console → Project settings → Web app конфигі (JSON бір жолмен) |
| `AUTH_REQUIRED` | `1` (әдепкі) — Firebase қосулы болса, әр адам Google/телефон арқылы кірмейінше сайтты қолдана алмайды. `0` — кіру міндетті емес |
| `AUTH_PHONE` | `1` — телефонмен кіру батырмасы көрсетіледі (әдепкі: жасырын). SMS жіберу тек Firebase **Blaze** (төлемді) жоспарында жұмыс істейді |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` | Telegram-бот (@BotFather-ден токен; secret — кез келген ұзын сөз) |
| `ANTHROPIC_API_KEY` | AI-көмекші |

**Firebase:** console.firebase.google.com → жоба ашу → Authentication → Sign-in method: Google және Phone қосу →
Settings → Authorized domains-ке Render доменін қосу → Project settings → Web app тіркеу → конфигті `FIREBASE_WEB_CONFIG`-ке салу.
Service-account JSON **керек емес** және оны ешкімге берме.

**Telegram webhook** (бір рет, браузерде ашу):
`https://api.telegram.org/bot<TOKEN>/setWebhook?url=<BZ_SITE_URL>/api/telegram/<SECRET>`

**Беттер:** `#/plan` — Менің жоспарым (балл, грант мүмкіндігі, мерзімдер, PDF);
`/u/029`, `/m/B057` — іздеу жүйелеріне арналған беттер; `/sitemap.xml`; `/admin.html` — статистика (IP сақталмайды).
Сайт телефонға қосымша ретінде орнатылады (PWA, https-те ғана).

## Render-ге орналастыру (тегін)

1. https://render.com сайтына GitHub аккаунтыңмен кір.
2. **New → Blueprint** бас да, `BilimIzde` репозиторийін таңда. Render `render.yaml` файлын өзі оқиды.
3. Render `ANTHROPIC_API_KEY` мәнін сұрайды. AI керек болмаса, бос қалдыр.
4. **Apply** бас. Бірнеше минуттан кейін сайт `https://bilimizde.onrender.com` сияқты адреспен ашылады.
5. Әр `git push` жасаған сайын сайт өзі жаңарады.

Тегін тарифке қатысты екі ескерту:
- Сайтқа 15 минут ешкім кірмесе, сервер «ұйықтап» қалады. Келесі кіргенде бет 30–50 секундта ашылады.
- Тегін тарифте диск тұрақты емес. Сервер қайта қосылса, клуб пікірлері өшіп қалады. Пікірлер тұрақты сақталсын десең, ақылы Render Disk қосып, `BZ_DB_PATH` айнымалысына сол дисктегі жолды көрсет (мысалы `/var/data/bilimizde.db`), немесе сыртқы дерекқор қолдан.

## Деректерді жаңарту

- **ЖОО мамандықтары, жатақхана, әскери кафедра:** `backend/app/data/university_extra.json`. Әр ЖОО коды бойынша:
  - `programs` — мамандық топтарының шифрлары;
  - `dorm` — `true` (бар) немесе `null` (белгісіз);
  - `military` — `true` немесе `false`;
  - `*_src` — дереккөз сілтемесі.
- **Аудармалар:** атаулар `backend/app/data/i18n.json` ішінде, интерфейс мәтіндері `frontend/js/i18n.js` ішінде. Жаңа мәтін қоссаң, сөздікке `['қазақша', 'орысша', 'english']` жолын қос.

Дереккөздер (тексерілген күні 16.11.2026):
- Мамандықтар: ЕПВО Білім беру бағдарламаларының тізілімі (univision.kz арқылы).
- Әскери кафедралар: eGov.kz «Военные кафедры при ВУЗах РК» тізімі (36 ЖОО).
- Жатақхана: ЖОО сайттары, gov.kz және ресми жаңалықтар. 35 ЖОО расталды, қалғаны «Белгісіз» деп көрсетіледі.
